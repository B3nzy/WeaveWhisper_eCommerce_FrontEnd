# WeaveWhisper - Frontend

The client-side web application for **WeaveWhisper**, a responsive, feature-rich e-commerce clothing marketplace designed to bridge independent clothing brands with customers.

## 🛠️ Tech Stack
* **Core Library:** React.js (Vite-optimized for rapid Hot Module Replacement)
* **State Management:** Redux Toolkit (Predictable global state for cart, authentication, and user sessions)
* **Styling:** Tailwind CSS (Utility-first fluid layout design)
* **Build Tool:** Vite
* **Libraries:** Axios, React Router DOM

## 🚀 Key Features Implemented
* **Dual User Roles:** Complete workflows for both **Customers** (browsing, dynamic search filters, wishlists, dynamic cart, order tracking) and **Brands** (onboarding portal, product upload, inventory catalog management).
* **Advanced Search & Filtering:** Implemented robust client-side search parsing with real-time pagination, infinite scroll logic, and multi-tier attribute filtering.
* **Brand Autonomy Dashboard:** A full-featured analytics and operations dashboard built for vendor brands to track client orders, modify statuses, and manage live listings.
* **Secure UI Flow:** Implemented route guards (Protected Routes) using Redux state to isolate secure checkout pages, wallet profiles, and administration panels.
